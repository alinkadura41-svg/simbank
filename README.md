# SimBank — индивидуальный мини-проект ООАП

## Что делает система
SimBank — учебная модель мобильного банковского приложения для клиентов, которым нужно просматривать счета, баланс и историю операций, а также отправлять переводы. Клиент может создать перевод и отслеживать его статус. Сотрудник поддержки просматривает обращения и обновляет их статус. Проект описывает требования, классы, сценарии и REST API; это учебная модель, а не описание реального API банка.

## Роли
- **Клиент** — просматривает свои счета и операции, создаёт переводы и проверяет их статус.
- **Сотрудник поддержки** — просматривает обращения и обновляет их статус.
- **Система платежей** — проверяет возможность перевода и обрабатывает операцию.

## Главный процесс
Создание перевода с проверкой суммы и доступного баланса.

## Пользовательские истории
1. Как клиент, я просматриваю список своих счетов, чтобы выбрать нужный счёт.
2. Как клиент, я проверяю баланс, чтобы понимать доступную сумму.
3. Как клиент, я открываю историю операций, чтобы проверить списания и поступления.
4. Как клиент, я создаю перевод, чтобы отправить деньги получателю.
5. Как клиент, я вижу статус перевода, чтобы понимать, выполнен ли он.
6. Как клиент, я отменяю неподтверждённый перевод, чтобы исправить ошибку до обработки.
7. Как сотрудник поддержки, я просматриваю обращение, чтобы понять проблему клиента.
8. Как сотрудник поддержки, я меняю статус обращения, чтобы клиент видел ход решения.

## Главный сценарий
Клиент отправляет запрос на перевод. API проверяет авторизацию и формат данных, сервис проверяет счёт и баланс, затем сохраняет перевод. Если данные неверны или средств недостаточно, операция не выполняется и клиент получает код ошибки.
