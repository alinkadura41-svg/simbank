# Журнал использования ИИ
- Использовал ИИ для структурирования учебного проекта SimBank: ролей, пользовательских историй и главного процесса.
- Использовал помощь для черновиков диаграмм, таблицы REST API и OpenAPI.
- Перед сдачей следует проверить диаграммы в Mermaid Live Editor / PlantUML, а OpenAPI — в Swagger Editor.
- Проект учебный; реальные банковские данные и секреты не использовались.
